# 角色与怪物属性 / 升级 设计稿

- 日期：2026-10-29
- 状态：已实现（2026-10-29）
- 范围：角色等级、四项属性、怪物属性、伤害公式、升级与面板

## 1. 角色属性

| 属性 | 作用 |
|---|---|
| 攻击力 | 增加玩家对怪物/野人的伤害 |
| 防御力 | 先按固定值减伤 |
| 护甲 | 防御减伤后再按百分比减伤，上限 70% |
| 移速 | 百分比移动速度，叠乘装备与等级 |

等级 Lv1–20。基础值：

- 攻击力 `4 + 2 × (Lv-1)`
- 防御力 `1 × (Lv-1)`
- 护甲 `2% × (Lv-1)`，上限 70%
- 移速 `1 + 1% × (Lv-1)`，上限 1.20

装备的 attack/defense/moveMul 在等级基础值之上叠加；装备护甲槽仍提供防御力，不额外改装备数据。

## 2. 经验与升级

`xpToNext(level) = 40 + 25 × level`（Lv1→2 需 65，Lv2→3 需 90，依次增长）。

经验来源：

| 行为 | XP |
|---|---|
| 采集一次资源 | 2 |
| 合成一次 | 3 |
| 钓到鱼 | 4 |
| 收获作物 | 5 |
| 击杀小动物 | 8 |
| 击杀野猪 | 18 |
| 击杀野人 | 25 |
| 击杀副本普通怪 | 8 |
| 击杀精英 | 25 |
| 击杀 Boss | 80 |
| 发现地标 | 15 |
| 存活过夜 | 10 |
| 通关一层沉船 | 30 |

升级时：等级 +1、剩余经验结转、`bus.emit('player:levelUp', {level})`；UIScene 弹横幅并播放音效。

## 3. 伤害公式

玩家打怪：

```
raw = (武器伤害 + 玩家攻击力) × 词条乘区
final = max(1, round((raw - 怪物防御) × (1 - 怪物护甲/100)))
```

怪物打玩家（`applyDamage`）：

```
final = max(1, round((怪物攻击 - 玩家防御) × (1 - 玩家护甲/100)))
```

- 防御最低减到 1 点伤害。
- 护甲上限 70%，避免无敌。
- 破甲词条只忽略防御，不忽略护甲。
- 环境伤害（机关、饥饿）也走玩家防御/护甲，保持一处公式。

## 4. 怪物属性

所有怪物拥有：等级、攻击、防御、护甲、移速、HP。

- 野人：Lv3，攻击 8，防御 0，护甲 5%，移速 40。
- 鸡/兔：Lv1，攻击 2/1，防御 0，护甲 0%，移速 20/45。
- 野猪：Lv3，攻击 10，防御 1，护甲 10%，移速 20/45。
- 鱼：Lv1，攻击 0，防御 0，护甲 0%，移速 22/48。
- 副本：螃蟹 Lv1、寄居蟹 Lv2、海蛇 Lv2、老鼠 Lv1、幽灵 Lv2；精英 +2 级、Boss +4 级；护甲随档位 +5/+10，上限 60%。

Boss 血条标题显示 `LvX 名称`。普通怪不额外做常驻面板，属性直接参与战斗计算。
