# 操作指引与手机按键显示 设计稿

- 日期：2026-10-29
- 状态：已实现（2026-10-29）
- 范围：触屏检测兜底、按钮标签、首次操作指引与重看入口

## 1. 手机按键显示

- `isTouchDevice` 增加 `(pointer: coarse)` 媒体查询与移动端 UA 兜底；`prefersTouchLayout` 不再限制短边 <900，任何触屏/粗指针设备都显示虚拟按键。
- 虚拟按键补充小标签：摇杆“移动”、攻击“攻击”、交互“交互/收线”、奔跑“奔跑”、菜单“菜单”。
- 触屏菜单改为 3×4：背包、合成、建造、劳工、地图、冒险、暂停、操作、按键、全屏、关闭。
  - “操作”打开指引。
  - “按键”切换虚拟按键显示；关闭后菜单仍保留，可随时重新打开。
- 暂停菜单“触屏控制”开关保留；检测失败时仍可通过触屏菜单/暂停菜单重新开启。

## 2. 首次操作指引

- 新增 `GuideScene`，两页：
  - 第 1 页：移动、奔跑、交互、攻击、石斧砍树。
  - 第 2 页：背包、合成、建造、劳工、地图、角色、暂停、快捷栏。
- 桌面显示键盘按键；手机显示屏幕按钮位置。
- 新档/旧档首次进入海岛时自动弹出；关闭时写 `flags.controlsSeen = true` 并保存。
- 之后可从暂停菜单右上角“操作指引”或触屏菜单“操作”重看。
- 指引打开时暂停当前游戏场景，关闭后恢复；不重置存档、不改变进度。

## 3. 存档

- `flags.controlsSeen?: boolean`，新档 false，旧档缺省 false（会看一次）。
- 存档版本保持 v5。

## 4. 测试

- `platform.test.ts`：触屏/粗指针在大屏也返回 true。
- `controlsGuide.test.ts`：桌面/手机各两页，包含对应按键/按钮文案。
- 手动：844×390 触屏显示摇杆/攻击/E/跑/菜单及标签；首次进入弹指引、翻页、关闭后不再自动弹；暂停/触屏菜单可重看；390×844 仍先横屏提示。
