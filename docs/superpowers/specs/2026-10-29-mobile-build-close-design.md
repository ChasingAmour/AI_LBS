# 手机端建造取消、面板关闭与图标修正 设计稿

- 日期：2026-10-29
- 状态：已实现
- 范围：手机端建造模式退出、面板关闭、tooltip 超时、图标/标签尺寸

## 1. 建造模式退出

- 建造卡片在选择前检查材料：材料不足时卡片禁用并显示“材料不足”，不再进入放置模式。
- 触屏进入建造模式后，右下角显示红色“× 取消”按钮；点击立即清除蓝图并退出。
- 建造模式下点“≡”也会直接取消建造，不会打开菜单。
- 桌面仍保留 Esc / 右键取消。

## 2. 面板与状态框关闭

- 触屏任意面板（背包/合成/建造/劳工/地图/冒险/触屏菜单）右下角显示常驻“×”关闭按钮，深度高于面板。
- 关闭按钮点击后关闭所有面板；地图原有“×”保留。
- 物品/装备 tooltip 4 秒后自动消失；再次点其他格子会替换。
- 状态栏折叠箭头增加 28×28 触控热区，位置随展开/折叠同步。

## 3. 图标与标签

- 快捷栏图标 32px → 26px，避免在 36px 格子里挤住数字/耐久。
- 虚拟按键标签重新排布：菜单在按钮上方，攻击/奔跑/交互在按钮下方，避免与圆形按钮重叠。
- 触屏菜单 3×4：新增“操作”“按键”，保留全屏/关闭。

## 4. 验证

- `buildMenu.test.ts`：材料不足禁用、材料齐全启用。
- 手动 844×390：建造模式红色取消可退出（buildSelection 变 null）、面板右下角 × 可关闭（uiOpen 变 false）、tooltip 自动消失、快捷栏图标不挤出。
- 全量 375 项测试、typecheck、lint、build 通过。
