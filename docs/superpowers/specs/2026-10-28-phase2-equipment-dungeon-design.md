# 阶段二：装备、沉船副本、音频与体验补齐 — 设计文档

- 日期：2026-10-28
- 状态：待批准
- 关联：`2026-10-28-robinson-crusoe-survival-design.md` §11 装备、§13 沉船副本；`2026-10-28-visual-overhaul-design.md` 验收与已知限制

## 1. 意图

阶段一已经能玩：生成岛、采集、合成、建造、劳工、周五入侵、存档和像素 UI。阶段二补上两条长期目标线（装备成长、沉船副本），并还清视觉与体验上的已知欠账（水面动画、地图缩放、物品图标、建造/劳工卡片、音频、60FPS 实测）。目标不是加更多系统，而是让已有循环有“值得反复玩”的深度。

## 2. 范围

### 做

- 武器/护甲/鞋子三装备槽：5 品级、随机词条、传说唯一词条、耐久与工作台修理。
- 装备来源：合成（普通）、普通宝箱、最终宝箱；首通传说保底。
- 沉船副本：三层、种子程序生成、敌人、环境机关、火把照明、每周宝箱重置。
- 装备属性接入战斗/移动/采集/需求；鞋子移速与涉水免疫。
- 音频：CC0 音效 + 传说掉落音效，音量/静音设置并写入存档。
- 已知限制：水面 3 帧动画、地图 1×/2× 缩放与拖动、物品图标、建造 2×4 卡片、劳工 520×72 卡片、60FPS 实测与必要优化。

### 不做

- 其他岛屿/大陆/航行、联机、多存档、手机触屏、天气季节、钓鱼农业、NPC 交易、剧情结局、成就、模组。
- 背景音乐（只做音效与传说短音；避免大体积循环音乐）。
- 重做装备掉落之外的战斗动作（沿用现有攻击形状）。

## 3. 约束

- 纯静态、无后端、GitHub Pages；`base: '/AI_LBS/'`。
- 存档单档 localStorage，键名 `robinson.save.v1`；版本升到 **v3**，v1/v2 必须可迁移。
- 所有随机使用带种子 PRNG；装备词条与副本布局读档后不变。
- 640×360 基准、整数缩放；正文 12px、标题 24px。
- 现有 174 项测试必须继续通过；新增纯函数测试。

## 4. 方案与取舍

### 4.1 副本生成：种子“船体骨架 + 侧舱”（已选）

- 每层一条主走廊（龙骨）贯穿，左右按种子摆放矩形舱室，门直连走廊；梯子在远端，入口在近端。连通性由构造保证。
- 备选：通用房间网格（更像地牢，不像船）、细胞洞穴（连通性难保证）。均放弃。
- 取舍：布局重复感靠种子与房间内容（机关/敌人/箱子组合）缓解；换来可控的走位与验收。

### 4.2 装备数值：派生属性纯函数（已选）

- `deriveStats(state)` 聚合已装备且耐久 > 0 的装备基础属性与词条，输出一组只读修正值；战斗、移动、采集、需求系统在调用点读取。
- 备选：事件/临时 Buff（状态多、易漏算）。放弃。
- 取舍：每次调用做一次小循环（≤3 件装备），可缓存但不必。

### 4.3 水面动画：区块 3 帧水变体（已选）

- 每个区块烘焙 3 张水帧（wave offset 0/1/2），每 450ms 切换；陆地帧共用。
- 备选：屏幕空间水波叠加（会盖到陆地，需遮罩）。放弃。
- 取舍：显存约 +18MB（9 区块 × 2 张额外 512² RGBA），换取零每帧重绘。

### 4.4 音频：CC0 素材 + Phaser Sound（已选）

- 从 Kenney 的 CC0 音频包下载短音效（UI、砍伐、采矿、拾取、合成、受击、开箱、传说、警报），OGG 体积小。
- 备选：程序化 WebAudio 合成（省素材，但质感差）。放弃。
- 取舍：需要联网下载一次并记录许可；不做循环 BGM。

## 5. 装备系统

### 5.1 数据

`src/data/equipment.ts`：

| 字段 | 说明 |
|---|---|
| `id` | 基础装备 id（club/spear/…/captain_boots） |
| `slot` | weapon / armor / boots |
| `name` | 中文名 |
| `base` | `{ attack?, defense?, moveMul?, energyMax?, shallowImmune? }` |
| `weaponId?` | 对应 `data/weapons.ts` 的攻击形状（仅武器） |
| `legendary` | `{ id, name, desc, effect }` 唯一词条 |

基础装备沿用设计文档 §11.4 的 14 件；新增武器形状进 `weapons.ts`（珊瑚匕首 combo、船长弯刀 arc 更快、海蛇骨矛 thrust + 毒、船锚锤 arc 慢重）。

**旧档兼容**：合成木棒/石矛现在产出普通装备实例；v2 存档里快捷栏/背包中的 `club`/`spear` 堆叠在迁移时转成同耐久的普通装备实例，旧快捷栏引用清空。装备实例不再进入普通物品堆叠。

### 5.2 品级与词条

- 品级：普通/精良/稀有/史诗/传说；词条数 0/1/2/3/3 + 传说唯一词条。
- 普通词条池按槽位分组（武器：攻击/眩晕/对野人/采集/耐久；护甲：防御/反伤/精力/耐久；鞋子：移速/饱食/精力/耐久），数值按 §11.3 的 T2–T5 档。
- 同一件装备不重复抽同名词条；传说额外追加基础装备绑定的唯一词条。
- 生成：`rollEquipment(rng, slot, rarity)` 纯函数；实例存入 `equipmentInstances`，词条数值落盘。

### 5.3 派生属性

`src/systems/equipmentSystem.ts`：

```ts
interface DerivedStats {
  attack: number; defense: number; stunMul: number; savageDmgMul: number;
  gatherMul: number; moveMul: number; energyMax: number; hungerMul: number;
  thorns: number; shallowImmune: boolean;
}
deriveStats(state): DerivedStats
```

- 只统计耐久 > 0 的已装备实例。
- 攻击：`weapon.damage + attack`；眩晕/对野人/采集/移速/精力/饱食/反伤按乘区或加区处理（表格写死）。
- 反伤：受到近战伤害时对攻击者造成 `thorns`（野人与副本敌人）。
- 耐力上限：HUD 与需求系统按 `energyMax` 钳制。

### 5.4 耐久与修理

- 武器命中 -1、护甲受击 -1、鞋子每移动 2000px -1。
- 归零时属性失效、图标红色裂纹，装备不消失。
- 工作台修理：每 20 点耐久消耗木 1 + 藤蔓 1（向上取整），传说额外布 1；一次修满。
- 修理入口：背包面板内、靠近工作台时显示“修理”按钮。

### 5.5 掉落

- 普通宝箱：普通 60% / 精良 30% / 稀有 8% / 史诗 2%，外加 1–2 份材料。
- 最终宝箱：首通必出传说；之后精良 40% / 稀有 30% / 史诗 20% / 传说 10%。
- 副本敌人：20% 掉布或燧石，不掉装备。
- `lootSeed` + `lootRolls` 存盘；每次开箱推进计数，保证同一存档结果稳定、测试可复现。

### 5.6 UI

- 背包左栏三装备槽：显示图标、品级颜色边框、耐久条；点击卸下。
- 右栏网格：材料/食物/工具 + 未装备的装备实例（占 1 格，品级色边框）；点击装备。
- tooltip：名称（品级色）、槽位、基础属性、词条列表、传说词条说明、耐久；工作台旁显示修理消耗。
- 快捷栏仍显示材料/工具/食物；武器装备优先于快捷栏武器。

## 6. 沉船副本

### 6.1 生成

`src/world/dungeonGen.ts`：

```ts
generateDungeonFloor(seed: number, floor: 1|2|3): DungeonFloor
```

- 网格：40×24（第 3 层 32×20）；16px 瓦片。
- 龙骨走廊水平贯穿 y 中部，宽 2 格；两侧各 3–4 个舱室（5–8 × 4–6），1 格门连走廊。
- 入口在左端，梯子/出口在右端；第 3 层出口通回岛上。
- 房间类型：普通舱、积水舱、塌落舱；机关按类型放置。
- 内容：每层 2–3 个敌人（第 3 层含海蛇），普通宝箱 1 个/层，第 3 层最终宝箱 1 个；位置由种子决定且在可达房间内。
- 校验：所有房间、宝箱、梯子从入口 BFS 可达；同种子同布局。

### 6.2 场景

- `DungeonScene`：单张 40×24 画布烘焙（地形），玩家复用，墙体阻挡用瓦片判定（同深水逻辑）。
- 摄像机 2× 跟随；黑暗遮罩；火把光圈 120px，无火把 40px；离开副本回岛上破船。
- 交互：E 开箱（1.5s 引导，受击中断）、E 上下梯、E 离开。
- 敌人：`dungeonEnemy.ts` 状态 + AI（食腐蟹集群、巨型寄居蟹缩壳减伤、海蛇突进后撤）；只能击杀，不掉装备。
- 机关：松动甲板（踩中 15 伤害 + 1s 硬直）、漏水舱（移速 -50%、精力 -1/s）、塌落木板（预警 1s 后 20 伤害）。
- 死亡：沿用现有死亡流程，次日营地醒来；本周已开宝箱不重置。

### 6.3 进入与周重置

- 岛上破船地标新增“进入沉船”交互，需手持耐久 > 0 的火把；否则提示“里面太黑了”。入口在宝箱旁偏移 24px，宝箱交互优先。
- `scene='dungeon'`、`dungeonFloor` 写档；读档若在副本则回到**本层入口**，敌人重置；本周已开的宝箱保持已开。层间上下梯在同一局内保留该层敌人状态，离开副本即全部重置。
- **副本内的岛上世界（已定 A）**：时间与需求继续；劳工采集、节点重生继续（沿用纯函数）；周五 18:00 入侵按“抽象结算”处理——不实时模拟野人拆家，黎明用现有 `resolveRaidDawn` 扣口粮/损坏建筑。躲副本不能免灾。
- 每周一 06:00 重置 `openedChestsThisWeek`、`clearedThisWeek`；`firstClearDone` 永久保留。若玩家在副本内，记 `pendingReset`，离开时结算。
- 火把燃料在副本内继续消耗；可在副本内用备用火把替换。

## 7. 音频

- 来源：Kenney CC0 音频包（RPG Audio / UI Audio / Impact Sounds），下载后挑选约 12 个 OGG：
  - UI：点击、开面板、关面板
  - 采集：砍树、采矿、拾取
  - 战斗：命中、敌人倒下、受击
  - 合成/进食/喝水/开箱/传说
  - 周五预警
- 实现：`src/systems/audio.ts` 封装 Phaser Sound；`playSfx(key)` 忽略未加载；首次用户手势后解锁。
- 设置：`settings = { muted, sfxVolume }` 写入存档；暂停菜单提供“音效 开/关”和音量三档。默认开、0.7。
- 许可：更新 `LICENSES.md`，记录包名、链接、CC0 与下载日期。

## 8. 已知限制补齐

- **水面动画**：3 帧水变体，450ms 切换；区块卸载时一并释放。
- **地图缩放/平移**：1×/2× 缩放（滚轮），拖动平移（限制在岛内），地标/玩家/路线随视口变换；小地图保持固定全岛。
- **物品图标**：`src/ui/itemIcons.ts` 把 item baseId 映射到 tilesheet 帧（木/石/燧石/藤/黏土/布/贝壳/鱼/椰子/浆果/烤鱼/鱼干/绷带/火把/斧/镐/木棒/矛/装备），快捷栏与背包使用图标 + 数量。
- **建造卡片**：2×4 卡片（256×64），名称、成本、耐久、锁定态；点击进入放置。
- **劳工卡片**：520×72，名称/忠诚/任务/产出，指派与放回按钮。
- **60FPS**：用浏览器 CPU profiling 实测岛上/副本/地图三处；低于 50FPS 时优先做节点分块可见性与文字节流；结果写入 README。

### 8.1 角色动画（本次新增）

- **行走**：以 `farm 109` 的 16×16 角色为底，生成 `player-idle` / `player-walk-a` / `player-walk-b` 三个贴图；两个行走帧重绘下半身（左右腿交替抬起 1px、双腿间留 2px 暗色缝隙），身体整体 1px 上下浮动，8fps 循环；停止时回到 idle。岛上与副本共用。
- **攻击**：不再用一次性 Graphics 弧线。攻击时角色朝目标方向**前冲 2px**（只改渲染偏移，不改碰撞体），同时生成一张 24×24 的月牙斩击贴图，按攻击角度旋转、按武器射程缩放，**在 160ms 内每帧跟随玩家位置**并淡出；因此移动中攻击不会留下“脱节”的弧线。
- **命中反馈**：命中时敌人白色闪光 80ms（沿用）；重击/传说命中附加轻微屏幕震动（可选，默认关）。
- 动画帧在 BootScene 生成一次（`ensurePlayerFrames`），IslandScene / DungeonScene 共用。

### 8.2 传说词条实现范围（已定 A）

全部实现，使用最小状态层：

- 数值型：攻击、防御、耐久、眩晕、对野人伤害、采集、移速、精力、饱食、反伤。
- 状态型：护甲穿透（单次无视防御）、中毒叠 2 层、减速 40%/2s、击退、击杀后 2s 攻速 +30%、奔跑精力 -50%、浅水免疫、击退减半。
- 敌人的防御/状态字段最小化：`defense`、`slowUntil`、`poisonStacks`、`knockback`；只服务这些词条，不扩展成通用 Buff 框架。

## 11. 风险与取舍

- 副本是最大风险：生成器与场景 AI 都可能拖期；先做生成器纯函数与可达性测试，再做场景。
- 装备数值会改变平衡：以“普通装 ≈ 阶段一强度”为基准，词条只做小幅加成；首通传说作为明确奖励。
- 水面 3 帧显存：若移动端/低配吃紧，可降为 2 帧或仅在深水启用。
- 音频素材：先下载后校验许可与体积；若包不可用，退回程序化短音。
- 存档 v3：迁移链必须有测试，避免线上旧档丢失。
