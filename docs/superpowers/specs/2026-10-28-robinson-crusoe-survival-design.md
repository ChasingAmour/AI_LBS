## 1. 概述

玩家扮演海难后漂流到荒岛上的幸存者，第一天清晨在沙滩的破船残骸旁醒来。白天探索、采集、合成、建造，夜里回营地点火休息；每 7 天一轮，**周五黄昏野人登陆**，玩家可以击晕并捆回野人，让他们替自己采集资源。建造建筑推动营地升级，营地等级决定可关押的野人上限。海边的大沉船是一个可反复挑战的三层副本，产出带品级与随机词条的装备。

目标体验：**“从一无所有到把荒岛变成自己的营地”**，节奏舒缓但不无聊，每周五有一次明确的高压事件。

### 1.1 与原著的呼应（风味层，不强制剧情）

- **海难与破船**：开局在残骸旁醒来，破船箱是第一批工具与布料的来源。
- **孤独与筑巢**：从露天睡沙滩到营火、栅栏、帐篷，对应鲁滨孙逐步把荒野变成“住所”的过程。
- **野人与星期五**：周五登陆的野人、击晕捕获与劳工，是“星期五”这条线的玩法化；**捕获的第一名劳工默认命名为“星期五”**。
- **未知的恐惧**：首版用周五 17:00 的鼓声与警告代替原著中的脚印事件，制造“有什么要来了”的压力。
- **离开荒岛**：其他岛屿与大陆留作后期目标，对应原著结尾的离岛与归航。

### 3.3 架构原则

- **数据驱动**：物品、武器、护甲、鞋子、词条、配方、建筑、营地等级、刷物、敌人、波次、掉落表全部是 TS 数据表；新增内容不改系统代码。
- **单一可序列化状态**：`GameState` 是唯一真相，所有系统读写它；存档 = 深拷贝 + 版本号。渲染层只做投影，不在精灵上保存游戏数据。
- **系统尽量纯函数**：接收 `GameState`、时间步长、注入的 RNG，返回变更或事件；便于 Vitest 覆盖。
- **事件总线**：`time:dayChanged`、`raid:started`、`savage:stunned`、`savage:captured`、`labor:fled`、`camp:levelUp`、`loot:granted` 等，解耦系统。
- **地图数据**：Tiled JSON（`.tmj`），三张图层：ground / decoration / collision；出生点、营地中心、资源点、宝箱、副本入口用对象层标记。
- **渲染**：基准分辨率 640×360，相机 zoom 2，`pixelArt: true`、`roundPixels: true`；深度 = 脚底 Y；树冠独立精灵，depth = 树底 Y + 8，实现遮挡。
- **寻路**：16px 网格 A*，野人/劳工每 1 秒或目标变化时重算，路径平滑后交给 Arcade 物理。
- **性能**：屏幕外资源节点与敌人关闭更新；文本每 200ms 刷新一次；粒子上限 200；目标 60 FPS。

### 3.4 启动与数据校验

BootScene 加载资源后执行一次数据完整性校验，失败直接显示错误页（不进入游戏）：

- 配方引用的物品/站点存在，产物存在
- 建筑升级条件引用的建筑存在
- 掉落表引用的装备基础 ID 与词条 ID 存在
- 地图对象引用的刷物点类型存在
- 营地等级单调递增，囚犯上限递增

## 4. 时间、星期与事件

### 4.1 时间轴

- 游戏从**第 1 天（周一）06:00**开始。
- 一个游戏日 = 15 分钟现实时间：
  - 白天 06:00–18:00 = 600 秒（1 现实秒 = 1.2 游戏分钟）
  - 夜晚 18:00–06:00 = 300 秒（1 现实秒 = 2.4 游戏分钟）
- 7 天为一个循环：第 1 天周一、第 2 天周二……**第 5 天周五**、第 7 天周日。
- **每周五（第 5、12、19…天）18:00** 野人登陆；17:00 出现鼓声与横幅预警。
- **每周一（第 1、8、15…天）06:00** 沉船副本宝箱重置。
- 睡觉推进到次日 06:00，并触发自动存档；`Esc` 暂停时时间停止（战斗中也一样）。

### 4.2 昼夜

- 夜晚全岛叠加冷色暗化，玩家周围有暖色光照半径（营火更大）。
- 夜晚移速不变，但视野缩小；后续可加夜行生物，首版不加。
- 在副本内时间照常流动；周五 18:00 若玩家在副本，HUD 警告“营地正在被袭击”，玩家可随时从出口撤离。

## 5. 玩家、需求与死亡

### 5.1 基础

| 项 | 数值 |
|---|---|
| 生命 | 100，无自然回血 |
| 饱食 | 100，-0.05/秒（约 45/天） |
| 口渴 | 100，-0.08/秒（约 72/天） |
| 精力 | 100，睡觉回满 |
| 移速 | 基础 90 px/s；Shift 奔跑 ×1.5，耗精力 0.4/秒 |

地形移速：草地 1.0、沙滩 0.9、树林 0.85、浅水 0.6（涉水鞋免疫浅水减速）、深水不可通行。

### 5.2 需求与后果

- 饱食或口渴归零：每 2 秒 -1 HP（0.5 HP/s）。
- 精力低于 10：采集/砍伐/挖矿/建造速度减半；精力为 0 时不能执行这些动作。
- 精力消耗：砍树 5、挖矿 6、采集 1、建造 10（每个建筑一次）。

### 5.3 恢复

| 来源 | 效果 |
|---|---|
| 溪流喝水（2 秒引导） | 口渴 +40 |
| 椰子 | 饱食 +10、口渴 +15 |
| 浆果 | 饱食 +8 |
| 烤鱼 | 饱食 +35 |
| 鱼干 | 饱食 +25（不腐败，用于劳工口粮） |
| 绷带 | 8 秒内回复 30 HP（受击不中断） |
| 睡觉 | 精力满、HP +20，推进到次日 06:00 |

### 5.4 死亡与重生

- 生命归零：屏幕淡出 → 掉落**背包内全部物品与快捷栏中的非穿戴物品**；已穿戴的武器/护甲/鞋子保留。
- 次日 06:00 在营地（营火或帐篷）醒来：HP 50、饱食 50、口渴 50、精力 100；若两者都没有，则在出生点破船旁醒来。
- 若死在副本：先被传送出副本，再按上述规则重生；副本进度清空，本周已开的宝箱不复原。
- 提示文案：“你失去了一切，但还活着。”

## 6. 岛屿世界

### 6.1 地图

- Tiled 手工地图 96×96 格，16px/格（1536×1536 世界像素）。
- 区域：西侧沙滩（出生点、破船残骸）→ 中部草地（营地空地）→ 树林 → 岩石坡（含浅洞）→ 东侧沙滩（沉船副本入口）→ 浅海 → 淡水溪流。
- 深水为硬边界；岛屿外围用礁石与浓雾表现不可通行。
- 营地空地固定，半径 12 格内可建造。

### 6.2 交互

- 靠近可交互物显示 `E 采集 / 拾取 / 睡觉 / 进入 / 喝水`。
- 按 E 开始 1.5 秒引导（进度环），移动、受击、打开面板会取消。
- 鼠标点击范围内物体同样触发。
- 所有交互走同一个交互器，优先级：敌人 > 劳工 > 建筑 > 资源节点。

### 6.3 资源节点（可破坏、双轨刷新）

| 节点 | 产出 | 耐久（次） | 再生 | 破坏表现 |
|---|---|---|---|---|
| 树 | 木头×3–5 | 4 次，每次 -1 | 3 游戏日 | 倒下留树桩 |
| 岩石 | 石头×2–3，30% 燧石 | 4 | 5 游戏日 | 碎成碎石堆 |
| 藤蔓丛 | 藤蔓×2 | 2 | 2 游戏日 | 枯萎留根 |
| 浆果灌木 | 浆果×2–3 | 2 | 2 游戏日 | 光秃枝条 |
| 椰子树 | 椰子×1 | 2 | 2 游戏日 | 保留树干 |
| 潮池 | 生鱼×1，50% 贝壳×1 | 1 | 1 游戏日 | 水面恢复 |
| 黏土坑 | 黏土×2 | 3 | 3 游戏日 | 留下浅坑 |

- 每个节点是独立实例，存档记录剩余耐久与再生日；再生在当日 06:00 结算。
- 采集需要对应工具才高效：无工具砍树 3 倍耗时；石斧/石镐为标准速度。

### 6.4 唯一物资（拿过永不再生）

| 位置 | 内容 | 条件 |
|---|---|---|
| 出生点破船箱 | 布×4、绷带×2 | 无 |
| 岩石坡山洞宝箱 | 燧石×5、布×2 | 手持点燃的火把 |

岛屿上的唯一物资按 ID 记录在 `world.uniqueLoot`，不参与周重置；沉船副本内的宝箱按周重置，见 13.5。

## 7. 物品、背包与合成

### 7.1 背包

- 24 格背包 + 8 格快捷栏，单格堆叠 99。
- 装备实例（武器/护甲/鞋子）各占 1 格、不可堆叠，带品级颜色边框。
- 工具（石斧/石镐/火把）占 1 格，带耐久/燃料条。
- 背包满时拾取失败并提示；快捷栏物品可拖拽。

### 7.2 物品清单（首版约 40 种）

- **原料**：木头、石头、燧石、藤蔓、黏土、布、贝壳、椰子、浆果、生鱼
- **加工**：木棍、绳子、火把、烤鱼、鱼干、绷带
- **工具**：石斧（60 次）、石镐（60 次）、火把（180 秒燃料）
- **武器**：木棒、石矛、珊瑚匕首、船长弯刀、海蛇骨矛、船锚锤（详见第 9 节）
- **护甲**：藤甲、贝壳甲、帆布衣、船长外套
- **鞋子**：草鞋、藤编涉水鞋、帆布靴、船长皮靴
- **建筑（建造菜单）**：营火、工作台、囚笼、帐篷、储物箱、木栅栏、石墙、晾肉架

### 7.3 合成站

| 站点 | 可做 |

| 手工（随时） | 木棍、绳子、木棒、火把、绷带 |

- 装备：见第 11 节。

## 8. 建筑与营地等级

### 8.1 建造流程

- `B` 打开建造菜单 → 选中建筑 → 半透明蓝图跟随鼠标并吸附 16px 网格。
- 绿色可放置，红色不可（压水、压资源节点、压敌人、超出营地半径、与已有建筑重叠）。
- 左键确认，扣除材料，播放 2–5 秒建造动画；期间移动不取消（建造是“施工”状态），但受击会中断并退还 50% 材料（向上取整）。
- 建筑可拆除，返还 50% 材料。

### 8.2 建筑功能

| 建筑 | 成本 | 耐久 | 功能 |
|---|---|---|---|
| 营火 | 木 10 + 石 8 | 100 | 烹饪、夜间大范围光照、重生点 |
| 工作台 | 木 15 | 80 | 高级合成、装备修理 |
| 囚笼 | 木 20 + 藤蔓 10 | 120 | 关押野人，决定上限 |
| 帐篷 | 木 20 + 布 4 | 80 | 睡觉推天、重生点 |
| 储物箱 | 木 15 + 藤蔓 4 | 80 | 30 格共享仓库，劳工卸货点；被破坏时内容物掉在脚下 |
| 木栅栏 | 木 3 | 60 | 阻挡野人 |
| 石墙 | 石 2 | 200 | 阻挡野人（Lv2 解锁） |
| 晾肉架 | 木 10 + 藤蔓 4 | 60 | 把生鱼制成鱼干（饱食 +25，可长期保存） |

### 8.3 营地等级

| 等级 | 升级条件 | 囚犯上限 | 解锁 |
|---|---|---|---|
| Lv1 | 营火 + 工作台 + 囚笼 | 1 | 石斧、石镐、石矛、烤鱼、绷带、帐篷 |
| Lv2 | 帐篷 + 储物箱 + 木栅栏×8 | 3 | 藤甲、贝壳甲、晾肉架、石墙 |
| Lv3 | 石墙×12 + 晾肉架 | 6 | 帆布衣 |

- 升级条件在升级瞬间校验已建成建筑数量与等级前置，不消耗额外材料；升级后营地等级不因建筑被拆或被毁而下降。
- 右上角常驻清单，实时显示每项进度，如 `木栅栏 3/8`。
- 升级瞬间播放短演出、解锁提示，并自动存档。

## 9. 战斗、武器与攻击模式

### 9.1 操作

- 鼠标左键攻击，朝向鼠标；攻击有前摇与后摇，期间移速 ×0.4。
- 每种武器由数据表定义**攻击形状**，首版三种：

| 形状 | 判定 | 适用 |
|---|---|---|
| 扇形横扫 `arc` | 以角色为圆心、射程为半径、指定角度的扇形，可命中多个目标 | 木棒、弯刀、船锚锤 |
| 直线突刺 `thrust` | 长条形判定，可穿透多个目标 | 石矛、骨矛 |
| 快速连击 `combo` | 3 段短扇形，每段独立判定、可叠加眩晕 | 珊瑚匕首 |
| 投射 `projectile` | 预留：飞行物、射程、穿透数 | 魔杖/远程（后期） |

- 同一次挥击对同一目标只结算一次（命中集合去重）。
- 攻击可击晕野人（见第 10 节），对副本敌人则直接扣血直至死亡；攻击不会伤害己方建筑与劳工。

### 9.2 武器数据（首版）

| 武器 | 形状 | 射程/角度 | 伤害 | 眩晕 | 冷却 | 耐久 | 获取 |
|---|---|---|---|---|---|---|---|
| 拳头 | arc | 24px / 60° | 4 | 12 | 0.45s | — | 默认 |
| 木棒 | arc | 36px / 90° | 8 | 20 | 0.65s | 40 | 手工 |
| 石矛 | thrust | 52px / 宽 14px | 14 | 6 | 0.80s | 50 | 工作台 |
| 珊瑚匕首 | combo | 26px / 70°，3 段 | 4×3 | 3×3 | 0.25s/段 | 45 | 副本 |
| 船长弯刀 | arc | 42px / 100° | 16 | 8 | 0.70s | 60 | 副本 |
| 海蛇骨矛 | thrust | 60px / 宽 16px | 18 + 中毒 3/秒×4 秒 | 6 | 0.90s | 55 | 副本 |
| 船锚锤 | arc | 40px / 120° | 12 | 28 | 1.10s | 70 | 副本 |

**设计意图**：钝器（拳头/木棒/船锚锤）眩晕高、伤害低，适合活捉；利器（矛/弯刀/匕首）伤害高但有击杀风险。副本内不能捕获，因此高伤武器更实用。

### 9.3 受击与无敌帧

- 玩家受击后 0.6 秒无敌帧，击退 12px。
- 护甲提供固定减伤（见第 11 节），最低伤害 1。
- 眩晕中的野人不再攻击；8 秒后眩晕值清零并继续战斗（HP 不回）。

## 10. 周五入侵与捕获

### 10.1 波次

- 每周五 18:00，东侧沙滩登陆：Lv0/Lv1 营地 2 名、Lv2 3 名、Lv3 4 名野人。
- 野人属性：HP 60、伤害 8、移速 70 px/s、攻击间隔 1.2 秒。
- AI 状态机：`approach → attack → stunned → retreat`。
  - 有木栅栏/石墙时优先拆墙（对建筑伤害 20/次）。
  - 墙破后冲向玩家或储物箱；黎明 06:00 撤退。
- 黎明结算：每名存活野人从储物箱拿走 5 份食物；食物不足则随机选取一栋可破坏建筑（木栅栏/石墙/储物箱/晾肉架）耐久 -30，没有则不额外破坏。黎明结算先于 06:00 自动存档执行。
- 周五 17:00 预警后到黎明，禁止睡觉与进入副本，避免跳过入侵。

### 10.2 击晕与捆绑

- 野人另有 100 点眩晕值，脱战 5 秒后每秒 -10；每次命中同时扣 HP 并增加眩晕值（数值见 9.2）。
- 眩晕值达到 100：野人眩晕 8 秒，头顶显示 `E 捆绑`；8 秒后眩晕值清零，继续战斗，HP 不回复。
- 按 E 消耗藤蔓×1，引导 2 秒；期间受击则中断（不消耗藤蔓）。
- 囚笼容量已满时提示“囚笼已满”，无法开始捆绑。
- 捕获成功：野人从战场移除，进入囚笼，转为劳工；`savage:captured` 事件更新 HUD。
- HP 先归零：野人死亡，尸体 10 秒后消失，无法捕获。钝器易眩晕、利器易打死，是武器选择的核心取舍。

### 10.3 难度与失败

- 玩家死亡按第 5.4 节处理；入侵继续，直到黎明。
- 首版不设“营地被摧毁 = 游戏结束”，最坏结果是丢食物与建筑耐久。

## 11. 装备系统

### 11.1 槽位

武器、护甲、鞋子三个槽位；工具不占装备槽。

### 11.2 品级与词条

| 品级 | 颜色 | 普通词条槽 | 来源 |
|---|---|---|---|
| 普通 | 白 | 0 | 合成、普通宝箱 |
| 精良 | 绿 | 1 | 普通宝箱、最终宝箱 |
| 稀有 | 蓝 | 2 | 最终宝箱 |
| 史诗 | 紫 | 3 | 最终宝箱 |
| 传说 | 金 | 3 + 1 条唯一特殊词条 | 最终宝箱（首通必出） |

### 11.5 耐久与修理

- 武器每次命中 -1；护甲每次受击 -1；鞋子每移动 2000px -1。
- 耐久归零：属性与词条失效（装备不消失），UI 显示红色裂纹。
- 工作台修理：每 20 点耐久消耗木 1 + 藤蔓 1（向上取整），恢复满耐久；传说装备修理额外消耗布 1。

### 11.6 掉落来源

- 合成：普通（0 词条），作为稳定保底装备。
- 普通宝箱：普通 60% / 精良 30% / 稀有 8% / 史诗 2%。
- 最终宝箱：首次开启必出 1 件传说；之后 精良 40% / 稀有 30% / 史诗 20% / 传说 10%。
- 副本敌人：20% 掉布或燧石，不掉装备。

## 12. 劳工系统

### 12.1 捕获后

- 被捕获的野人进入囚笼，成为劳工，初始忠诚 1，头顶显示忠诚星（1–3）与当前任务；第一名劳工默认命名为“星期五”。
- 劳工不参战、不受敌人攻击、不需要精力。
- 可召回、重新指派；也可“放归”（从囚笼消失，不返还资源）。

### 12.2 指派与采集

- 点击劳工 → 进入指派模式 → 点击一块区域（半径 8 格）→ 劳工自动寻找范围内最近的同类资源节点。
- 节点耗尽自动切换下一个同类节点；范围内没有节点时回营地待命并提示。
- 采集节奏：每 4 秒 1 份；背包容量 10；移速 60 px/s；走到储物箱卸货（无储物箱则卸在营火旁地面堆，玩家可走近按 E 取回）。
- 开采需要工具的节点（树/岩石）时，劳工自带等效工具，不消耗玩家工具耐久。

### 12.3 口粮与忠诚

- 每日 06:00 先结算口粮：从储物箱取 1 份食物（烤鱼/鱼干/椰子/浆果均算 1 份，优先级：鱼干 > 烤鱼 > 椰子 > 浆果），再结算忠诚；没有储物箱时视为没有口粮。
- 吃到：忠诚恢复 1（上限 3）。
- 没吃到：忠诚 -1；归零时立即逃跑，从营地消失，HUD 提示“一名劳工逃走了”。
- 忠诚只影响逃跑，不影响采集速度（首版不做士气加成）。

### 12.4 容量

- 上限 = 营地等级：Lv1=1、Lv2=3、Lv3=6。
- 超出上限的捕获请求被拒绝；劳工面板显示 `1/3`。

## 13. 沉船副本

### 13.1 入口与进入

- 东侧沙滩的大沉船残骸，按 E 进入；必须手持点燃的火把，否则提示“里面太黑了”。
- 独立场景 `DungeonScene`，按层加载三张 Tiled 地图；层间用梯子/舱门切换，保留当前层敌人状态。

### 13.2 三层结构

| 层 | 尺寸 | 敌人 | 机关 | 宝箱 |
|---|---|---|---|---|
| 上层甲板 | 32×24 | 食腐蟹×2 | 松动甲板（踩中 15 伤害 + 1 秒硬直） | 普通宝箱×1 |
| 货舱 | 32×24 | 巨型寄居蟹×1、食腐蟹×2 | 漏水舱室（移速 -50%、精力 -1/秒） | 普通宝箱×1 |
| 船长室 | 24×20 | 海蛇×1、食腐蟹×2 | 塌落木板（预警 1 秒后 20 伤害） | 最终宝箱×1、出口 |

### 13.3 敌人

| 敌人 | HP | 伤害 | 移速 | 行为 |
|---|---|---|---|---|
| 食腐蟹 | 15 | 5 | 45 | 集群靠近，短距钳击 |
| 巨型寄居蟹 | 80 | 12 | 30 | 缓慢逼近，缩壳减伤 50% 2 秒（冷却 6 秒） |
| 海蛇 | 40 | 10 | 80 | 突进撕咬，命中后后撤 |

- 副本内敌人**只能击杀，不能捕获**；击杀无装备掉落。
- 敌人每次进入副本重新生成；离开副本再进入即刷新。

### 13.4 照明与风险

- 副本内叠加黑暗遮罩，火把提供半径 120px 光照；火把熄灭后仅剩 40px 微光。
- 火把燃料 180 秒，可在副本内用备用火把替换（消耗 1 根）。
- 死亡：按 5.4 节，丢背包、次日营地醒来，副本内已开宝箱本周不重置。

### 13.5 宝箱与重置

- 普通宝箱：每周各可开一次，按掉落表产出 1 件装备 + 1–2 份材料。
- 最终宝箱：每周可开一次；首次开启必出传说，之后按 40/30/20/10 掉落。
- 每周一 06:00 重置所有宝箱与通关标记；若此时玩家在副本内，则延迟到离开副本后结算。敌人每次进入都重新生成。
- 宝箱开启有 1.5 秒引导与开箱动画，受击中断。

## 15. 存档与数据模型

### 15.1 存档策略

- 单档，localStorage key：`robinson.save.v1`；上一份自动存档保留为 `robinson.save.v1.bak`。
- 写入时机：每日 06:00、场景切换、手动存档、营地升级；入侵进行中禁止存档、睡觉与进入副本。
- 导出：下载 `robinson-save-YYYYMMDD-HHmm.json`；导入：校验版本与 schema 后覆盖当前档并重载页面。
- 读档失败（JSON 损坏/版本未知/校验不过）：提示并提供“使用备份”或“新游戏”，不静默开新档。

### 15.2 数据结构（SaveV1）

```ts
interface SaveV1 {
  version: 1;
  savedAt: number;            // epoch ms
  playtimeSec: number;
  rngState: number;           // 词条/掉落随机种子状态
  scene: 'island' | 'dungeon';
  dungeonFloor: 1 | 2 | 3 | null;
  time: { day: number; clockMin: number; phase: 'day' | 'night' };
  player: { x: number; y: number; hp: number; hunger: number; thirst: number; energy: number; facing: 'up'|'down'|'left'|'right' };
  inventory: ItemStack[];      // 普通堆叠物品
  hotbar: (string | null)[];   // instanceId 或 baseId
  equipment: { weapon: string | null; armor: string | null; boots: string | null }; // instanceId
  equipmentInstances: EquipInstance[];
  world: {
    nodeStates: Record<string, { remaining: number; respawnDay: number }>;
    uniqueLoot: string[];
  };
  camp: { level: 0 | 1 | 2 | 3; center: { x: number; y: number } };
  buildings: BuildingInstance[];
  laborers: LaborerState[];
  dungeon: { openedChestsThisWeek: string[]; clearedThisWeek: boolean; firstClearDone: boolean; resetDay: number };
  flags: { tutorialStep: number; raidWarnedDay: number; firstRaidDone: boolean };
}

interface EquipInstance {
  instanceId: string;
  baseId: string;              // 对应 weapons/armor/boots 数据
  slot: 'weapon' | 'armor' | 'boots';
  rarity: 'common' | 'fine' | 'rare' | 'epic' | 'legendary';
  affixes: { id: string; value: number }[];
  uniqueTraitId?: string;
  durability: number;
  maxDurability: number;
}

interface BuildingInstance {
  id: string;
  type: string;
  x: number; y: number;
  hp: number;
  storage?: ItemStack[];       // 储物箱内容
}

interface LaborerState {
  id: string;
  name: string;
  x: number; y: number;
  loyalty: 0 | 1 | 2 | 3;
  task: { nodeType: string; x: number; y: number } | null;
  carrying: number;
  carryingType: string | null;
}
```

- `itemId` 全部使用稳定字符串 ID（如 `wood`、`stone_axe`），显示名在数据表中，方便以后做多语言。
- `ItemStack = { baseId: string; count: number; instanceId?: string }`；装备实例由 `instanceId` 引用 `equipmentInstances`。
- 世界节点与建筑使用地图对象名 + 序号作为稳定 ID（如 `tree_012`）。

## 18. 资源与许可

- **贴图**：Kenney（CC0）、itch.io 上明确 CC0 的像素包、OpenGameArt CC0。避免 LPC（CC-BY-SA / GPL）进入首版，除非在游戏内做完整署名并接受传染性条款。

## 21. 术语

- **营地等级**：由已建成建筑清单决定的进度等级，决定囚犯上限与解锁。
- **劳工**：被捕获并关押的野人，可指派采集。
- **品级**：装备稀有度，从普通到传说共 5 档。
- **词条**：装备上的随机属性加成；传说装备额外拥有一条唯一特殊词条。
- **攻击形状**：武器决定的命中判定类型（扇形/直线/连击/投射）。
- **双轨刷新**：可再生资源按日/周重生，唯一物资永久一次性。
