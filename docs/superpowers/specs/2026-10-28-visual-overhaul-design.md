# 《鲁滨孙：荒岛求生》视觉、UI 与岛屿规模重做设计

- 日期：2026-10-28
- 状态：待批准（v2，已并入 10000×6000 岛屿与全岛地图）
- 关联文档：`docs/superpowers/specs/2026-10-28-robinson-crusoe-survival-design.md`
- 视觉稿：`docs/design/scene-camp.png`、`docs/design/inventory.png`、`docs/design/island-map.png`（已按用户反馈改为 **2×2 棚屋** 与 **羊皮纸旧地图** 风格）
- 目标：解决文字模糊、占位贴图、界面拥挤；把岛屿从 96×96 手工地图升级为 **10000×6000 世界像素** 的程序化岛屿；为阶段二装备/副本 UI 打底。

---

## 1. 现状与问题

当前实现已经跑通完整生存循环，但视觉层与世界的规模都还是临时方案：

- HUD 使用 8–11px 系统 `monospace`，在 640×360 画布上先以 8px 渲染，再被浏览器放大 3 倍，中文字形必然发糊。
- 角色、树木、岩石、浆果、建筑全部由 `IslandScene.makeTextures()` 用 Phaser Graphics 画矩形/圆形，缺少细节与光影。
- 地图使用 `public/assets/tiles/placeholder.png`，8 个纯色瓦片，没有海岸线、草地纹理、水面变化。
- 岛屿只有 96×96 格（1536×1536 世界像素），从出生点走到任何海岸都不超过 1 分钟，没有探索空间。
- 面板是 420×300 的纯文字列表，没有图标、没有滚动、没有选中态；右上角营地清单最多 5 行，容易和时钟/目标文字挤在一起。
- 快捷栏 26px 格子 + 8px 物品名，既看不清也占空间。
- 暂停/死亡界面只有文字和系统字体，和游戏世界完全脱节。

这些问题不是“再画几个矩形”能解决的，需要一次资产、字体、布局、组件与世界生成的整体替换。

## 2. 目标与非目标

### 2.1 目标

- 在 1920×1080、2560×1440、3840×2160 下文字清晰，像素不被非整数缩放拉糊。
- 世界贴图全部换成 Kenney 16×16 像素素材 + 少量手绘像素物件，不再出现程序化占位图。
- HUD 与所有面板使用统一主题、统一字号、统一交互反馈。
- 物品、配方、建筑、劳工、装备槽都有图标与 tooltip。
- 岛屿升级为 **10000×6000 世界像素（625×375 格）**，种子化生成，5 个区域、7 个地标。
- 新增全岛地图（M）与迷雾/探索度，地图采用羊皮纸旧地图风。
- 保持 60 FPS，保持现有 114 项测试通过。
- 存档升级到 v2：只存种子、已探索区块与实体状态，不存地形；v1 存档可迁移。
- 为阶段二的三装备槽、品级颜色、词条 tooltip 预留 UI 结构。

### 2.2 非目标

- 不在本次实现阶段二的装备掉落、词条、沉船副本玩法。
- 不新增四向行走动画；角色采用正面帧 + 水平翻转 + 1px 行走起伏。
- 不做手机触屏、手柄、多分辨率 UI 布局。
- 不新增音频、天气、季节、钓鱼、农业、NPC 交易。
- 不做其他岛屿、大陆与航行；本作只有这一座 10000×6000 的岛。
- 不做动态区域事件链、势力、剧情分支。

## 3. 美术方向

### 3.1 关键词

**Tiny 像素田园 × 鲁滨孙荒岛**：暖沙、青草、深青海水、木质/羊皮纸 UI、金色高光。整体比现在更明亮、更有“可居住感”，但仍然保留荒岛的孤独与夜晚压力。

### 3.2 素材选择

用户提到的 **Kenney Mini Arena 是 3D 低模包**（20 个 OBJ/FBX/glTF 模型），不是 2D 像素素材。直接预渲染会得到 3D 低模风格，与 16px 地形、像素角色难以统一，因此本次不采用。

采用 Kenney 的 2D 像素系列，全部 CC0：

| 素材包 | 用途 | 规格 |
|---|---|---|
| [Tiny Town](https://kenney.nl/assets/tiny-town) | 草地、沙地、泥地、树木、灌木、石墙、木墙、工具 | 16×16，132 帧 |
| [Tiny Battle](https://kenney.nl/assets/tiny-battle) | 深水、浅水、海岸、溪流、浪花 | 16×16，198 帧 |
| [Tiny Dungeon](https://kenney.nl/assets/tiny-dungeon) | 角色、野人、怪物、箱子、栅栏、营火、武器、药水 | 16×16，132 帧 |
| [Tiny Farm](https://kenney.nl/assets/tiny-farm) | 作物、浆果、藤蔓、动物、栅栏、木箱、石块 | 16×16，132 帧 |
| [UI Pack - Pixel Adventure](https://kenney.nl/assets/ui-pack-pixel-adventure) | 面板、按钮、格子、进度条、圆环、箭头、横幅 | 16×16 小件 / 32×32 大件 |

## 4. 分辨率与像素规则

- 内部画布保持 **640×360**，16px 瓦片，相机 zoom 2（可视 20×11.25 格）。
- **整数倍缩放**：1920×1080 用 3×，2560×1440 用 4×，3840×2160 用 6×；不能整除的窗口用整数倍 + 黑边居中，禁止 Phaser `FIT` 产生 2.13× 这类分数缩放。
- `pixelArt: true`、`roundPixels: true`、`antialias: false`。
- CSS `image-rendering: pixelated`。
- UI 坐标全部取整；图标只允许 1×（16px）或 2×（32px），文字只允许 12px 或 24px。
- 不再对单个精灵做 1.5×、1.25× 缩放；需要更大就换 32px 图标或 2 格高预制体。
- 手绘件以 16px 网格为基准，笔触为 2px（即源像素 1px × 相机 zoom 2）。

## 5. 岛屿世界（10000×6000）

### 5.1 规模与生成

- 世界尺寸 **10000×6000 世界像素**，16px 瓦片 → **625×375 格**，共 234,375 格，约 **31×33 屏**。
- 手工 Tiled 地图不可行（23 万格），改为 **种子化程序生成 + 手工地标模板**。
- 生成管线（全部在 `src/world/generate.ts`，纯函数、可单测、禁止 import Phaser）：
  1. **形状**：6 个椭圆“瓣”取并集（主岛、南岸、东雨林、西潮汐湾、北高地、东北石阵），再叠加 2 层 domain warp（±500px），得到海湾、半岛与狭颈；不使用单一圆形衰减。
  2. **高度**：`h = 0.52 + 0.30 × 形状场 + fBm 噪声`；按阈值划分深水 / 浅水 / 沙 / 陆地。
  3. **区域**：5 个区域锚点 + 每锚点独立噪声扰动的 Voronoi，边界有机；区域决定地表色、资源权重、地标归属。
  4. **河流**：从高地泉眼到潮汐湾，沿高度梯度下降生成，宽 1–3 格，遇到海面结束。
  5. **小径**：连接地标的最小生成树 + 弯曲噪声，宽 1 格，移速 +10%，是玩家的天然引导。
  6. **地标**：按区域规则放置，保证最小间距、可达性与“首小时动线”。
- 固定规则：
  - 出生点在南岸沉船旁，面向内陆。
  - 营地距沉船 ≤ 2 屏，营地中心必在草地且 5×5 格平坦。
  - 淡水泉在营地 1.5–2 屏内，是第一个引导目标。
  - 山洞、石阵、瞭望岩、旧营地分布在另外 4 个区域，必须跨区域才能到达。
- 世界生成是确定性的：同一种子 + 同一版本 → 完全相同的岛屿；生成结果带 `worldHash`，载入时校验。

### 5.2 区域与地标

| 区域 | 地貌 | 主要资源 | 地标 |
|---|---|---|---|
| 海岸平原 | 沙滩、草地、稀疏棕榈 | 椰子、浮木、鱼、贝壳 | 营地、沉船 |
| 雨林 | 密林、藤蔓、蘑菇 | 木材、藤蔓、浆果 | 山洞 |
| 高地 | 岩石、稀树、山脊 | 石、黏土、稀有矿 | 瞭望岩 |
| 潮汐湾 | 红树、浅滩、潮池 | 鱼、贝壳、黏土 | 旧营地 |
| 石阵荒野 | 碎石、枯草、石柱 | 稀有矿、宝箱 | 石阵 |

- 地标是手工模板（形状、碰撞、交互点固定），位置由生成器按区域规则落点。
- 地标发现后写入 `world.discovered`，地图上显示图标与名称；未发现只显示“未确认地标”菱形。
- 区域名与地标名用于 HUD 的“当前区域”和地图侧栏。

### 5.3 地形：逻辑层与视觉层分离

保留现有 8 个逻辑地形类型与碰撞/移速规则：

`deepWater / shallowWater / sand / grass / forest / rock / stream / clay`

地图不再来自 Tiled 文件，而是生成器输出的 `Uint8Array` 逻辑层。运行时在其上叠加可视层：

- `terrainTypeAt(x, y)` 仍然供 `placementWorld()`、`terrainSpeedAt()` 使用，玩法不变。
- 水面独立 3 帧动画，不改逻辑 ID。
- 草地/沙地/岩石各 3 个变体，按固定哈希选择，避免整片同图。
- 海岸线用 4-bit 邻接选择（水/沙/草），不需要 47 格完整 autotile。

视觉来源：

| 逻辑类型 | 视觉来源 | 说明 |
|---|---|---|
| 深水 | Tiny Battle 水面帧 | 3 帧循环，约 450ms/帧 |
| 浅水 | Tiny Battle 海岸/浅水帧 | 靠岸处加浪花叠层 |
| 沙 | Tiny Town 沙地 + Tiny Battle 海岸 | 3 变体，海岸线用邻接帧 |
| 草 | Tiny Town 草地 | 3 变体，和 Tiny Battle 草地同源 |
| 森林 | Tiny Town 草地 + 深色 tint | 不新增碰撞，只做地面表现 |
| 岩石 | Tiny Town 石地 / Tiny Farm 石块 | 3 变体 |
| 溪流 | Tiny Battle 水面 | 2 帧流动 |
| 黏土 | Tiny Town 泥地 | 3 变体 |

装饰层（无碰撞，固定种子随机）：

- 草簇、小花、小石子、贝壳、漂流木、脚印。
- 每个区块最多 1–2 个，避免满屏噪点。
- 装饰不参与 Y-sort，深度固定在地面之上、角色之下。

### 5.4 资源节点

全部改为 Kenney 精灵 + 手绘件，不再用 Graphics：

| 节点 | 表现 |
|---|---|
| 树 | 手绘圆冠阔叶树（3 个色调）+ Tiny Farm 松树混搭；树冠独立层，保留遮挡；耗尽后显示树桩 |
| 棕榈 | 手绘棕榈，2 个变体，椰子点缀 |
| 岩石 | Tiny Farm 石块 / Tiny Town 石堆，2 个变体；耗尽后缩小 + 变暗 |
| 藤蔓 | Tiny Farm 藤蔓，2 个变体 |
| 浆果 | Tiny Farm 浆果丛，满/空两种状态 |
| 潮池 | Tiny Battle 浪花 + 小鱼闪光，2 帧 |
| 黏土 | Tiny Town 泥堆 + 黏土色高光 |
| 宝箱 | Tiny Dungeon 宝箱，关闭/打开两帧 |

所有节点：

- 原点 `(0.5, 1)`，深度 = 脚底 Y。
- 脚下一块 10×4、alpha 0.25 的椭圆阴影。
- 耗尽状态用“树桩/空丛/碎石”表现，不再只把 alpha 调到 0.3。
- 交互高亮：1px 金色描边或脚下圆环，不改变精灵本身。

### 5.5 建筑

| 建筑 | 视觉组合 |
|---|---|
| 营火 | Tiny Dungeon 火焰 + 石圈 + 木柴，2 帧跳动 |
| 工作台 | Tiny Dungeon 木桌 + 工具叠层 |
| 囚笼 | Tiny Dungeon 栅栏拼合 + 阴影 |
| 棚屋（营地） | **2×2 手绘**：木墙 + 茅草顶 + 石基 + 烟囱 + 暖光门；替换原 3×3 帐篷 |
| 储物箱 | Tiny Dungeon 箱子 / Tiny Farm 木箱 |
| 木栅栏 | Tiny Farm 栅栏，可横向拼接 |
| 石墙 | Tiny Town 石墙，可横向拼接 |
| 晾肉架 | Tiny Dungeon 栅栏 + 红色肉条 |

- 棚屋占 64×64 世界像素（2×2 格），比原帐篷少占 1/3 画面，给角色与资源留出视野。
- 建筑原点 `(0.5, 1)`，深度 = 脚底 Y。
- 放置预览使用同一贴图，alpha 0.55，绿色/红色 tint，格子吸附。
- 可拼接建筑（栅栏、石墙）按左右邻居选择连接帧；首版可以先不做完整连接，但视觉上不能出现明显断裂。

### 5.6 角色

- **玩家**：Tiny Farm/Dungeon 人类帧，16×16，原点底部；碰撞体保持 10×8。
- **野人**：人类基础帧 + 骨面具/羽毛叠层 + 长矛，2 种 tint。
- **星期五/劳工**：不同人类帧 + 颜色点缀；工作时在手里叠一个工具小图标。
- 行走：水平翻转 + 每 8 帧 1px 上下起伏；不新增四向帧。
- 攻击：在角色前方叠武器帧 + 现有挥砍弧线，武器帧跟随攻击方向旋转/翻转。
- 阴影：脚下 10×4 椭圆，alpha 0.25。
- 受击：白色 flash 80ms；眩晕：蓝色 tint + 头顶星星/圈。

### 5.7 深度与遮挡

- 继续使用 `depthFor(y)`。
- 树冠独立精灵，`depth = 树底 Y + CANOPY_OFFSET`。
- 棚屋、石墙、工作台等高于 1 格的建筑，原点底部，按脚底 Y 排序。
- 阴影深度 = 脚底 Y - 1；地面装饰深度 = 0–100；角色/节点按 Y。
- 夜间叠加与玩家光源保持现有深度层级，不参与 Y-sort。

### 5.8 光照与昼夜

- 夜间叠加色 `#081a33`，alpha 0.55；黎明/黄昏各加一层暖色 tint（alpha 0.08–0.12）。
- 玩家光圈保持暖色；营火光圈半径 96px，火把 64px。
- 营火/火把加 2px 幅度的 alpha 呼吸，不做物理光照。
- 低血量：屏幕边缘红色 vignette，alpha 0.12–0.2 呼吸；低饱食/口渴：边缘轻微去饱和/变暗。
- 不做 shader，保证低端集显也能 60 FPS。

## 6. 字体与文本

### 6.1 字体

- 使用 **Fusion Pixel 12px**（OFL-1.1），随包分发 woff2 与其许可证。
- `@font-face` 放在 `src/style.css`，`font-display: swap`。
- 启动时 `await document.fonts.load('12px "Fusion Pixel 12px"')`，加载失败则回退 `monospace` 并在控制台警告；验收要求字体加载成功。
- 字体家族名以实际 woff2 内部名为准，集中在 `src/ui/theme.ts` 定义。

### 6.2 字号与排版

| 用途 | 字号 | 行高 |
|---|---|---|
| 正文、按钮、列表、tooltip | 12px | 16px |
| 面板标题、事件横幅标题 | 24px | 28px |
| 数字/计数 | 12px | 16px |

- **不再使用 8/9/10/11/13/14px**；次要信息用颜色/alpha 区分，不靠缩小字号。
- 文本 `resolution: 1`，坐标取整，禁止对 Text 做分数缩放。
- 中文正文颜色 `#f0e6d2`，羊皮纸底上用 `#2b2118`；金色 `#ffd479` 只用于标题/重点；弱化文字 `#b8a88a`。
- 需要描边时用 1px 偏移的深色 shadow，不用模糊阴影。

### 7.3 HUD 更新策略

- 文本每 200ms 更新一次；进度条每帧更新。
- 只有数值变化时才 `setText`，避免每帧重建文本纹理。
- 事件横幅使用队列，避免连续事件互相覆盖。
- 低状态/受伤效果用全屏矩形 + alpha tween，不新建粒子。

### 9.2 资产管线

- `scripts/build-assets.mjs` 只复制运行时需要的 packed tilesheet，不把 500+ 单张 PNG 全部塞进仓库。
- `scripts/build-terrain-atlas.mjs` 读取 Kenney 源图，生成 `terrain.png` 与 `terrain.json`：
  - 8 类地形 × 3 变体；
  - 水面/溪流 3 帧；
  - 海岸线 4-bit 邻接帧（水/沙/草）；
  - 装饰帧（草簇、花、石子、贝壳）。
- 使用 `pngjs`（devDependency）读写 PNG，保证脚本可在 CI 重现。
- 资产生成脚本幂等；`npm run assets` 重新生成，CI 构建前校验产物存在。

### 9.3 世界生成与区块

- `generateIsland(seed)` 返回：
  - `terrain: Uint8Array(625×375)` 逻辑地形；
  - `regions: Uint8Array` 区域 ID；
  - `landmarks: Landmark[]`；
  - `rivers`、`trails`、`spawn`、`campCenter`；
  - `hash: number`。
- 生成器只依赖 `core/rng.ts`，不依赖 Phaser，可直接在 Vitest 里断言：出生点在海滩、营地 5×5 平坦、淡水泉距离、所有地标可达、同种子同结果。
- 区块：32×32 瓦片（512×512 世界像素）。
  - 维护以相机为中心的 3×3 区块；进入时创建/复用 `RenderTexture`，离开时释放。
  - 每个区块首次进入时把地面 + 装饰烘焙到一张 512×512 贴图，之后每帧只画 9 张图，而不是 230 个瓦片精灵。
  - 水面动画区块单独保留 tileSprite 层，不参与烘焙。
- 碰撞：按瓦片查询（`terrainSpeedAt`），不给每格建物理体；只有玩家/敌人/建筑有物理体。
- 实体：节点、建筑、掉落物按区块索引；只更新/绘制相机周围 2 屏内的实体。
- 内存预算：9 个区块贴图 ≈ 9MB；实体 ≤ 300；瓦片数据 234KB。

### 9.4 存档 v2

- `GameState.version = 2`，新增：
  - `world.seed: number`
  - `world.hash: number`
  - `world.explored: string`（每区块 1 字节的 base64 位图，625×375 格 → 20×12 区块 = 240 字节）
  - `world.discovered: string[]`
  - `world.waypoint: { x, y } | null`
- 不再保存 `world.nodes` 的全量坐标：节点由种子 + 区域规则重建；只保存被改变的状态（`nodeStates` 的 key 为 `type:chunkX:chunkY:index`）。
- `wreckSpawn`、`camp.center` 由生成器给出，存档只存玩家改动。
- v1 → v2 迁移：
  - 读取 v1 存档时生成新岛，保留玩家属性、背包、营地等级、时间、已解锁配方；
  - 旧地图上的建筑/劳工位置按比例映射到新营地附近；
  - 首次载入弹一次横幅：“世界已扩展，旧地图上的资源点已重新分布”。
- 导出/导入 JSON 与 localStorage 共用同一 schema；导入时校验 `version`、`seed`、`hash`。

### 9.5 字体加载

- `src/style.css`：

```css
@font-face {
  font-family: 'Fusion Pixel 12px';
  src: url('/AI_LBS/assets/fonts/fusion-pixel-12px.woff2') format('woff2');
  font-display: swap;
}
```

- `main.ts` 改为 async 启动：

```ts
await document.fonts.load('12px "Fusion Pixel 12px"');
new Phaser.Game({ ... });
```

- Vite `base` 是 `/AI_LBS/`，字体 URL 必须走 `import.meta.env.BASE_URL` 或相对路径，不能写死根路径。
- 如果字体加载失败，回退 `monospace` 并 console.warn；截图验收会检查字体是否真的生效。

### 9.6 文本与像素对齐

- `makeText()` 统一设置 `resolution: 1`、`roundPixels: true`、整数坐标。
- 所有 Text 的 `setOrigin` 使用 0/0.5/1，不出现 0.33 这类值。
- 图标使用 `setDisplaySize(32, 32)` 或 `setScale(2)`，只允许整数倍。
- 面板/按钮尺寸全部为偶数，避免 1px 半像素边框。

### 9.7 性能

- HUD 文本 200ms 节流；进度条每帧。
- 区块烘焙：每帧最多烘焙 1 个区块，避免卡顿；首次进入新区域允许 1 帧 8ms 的峰值。
- 可视瓦片 ≈ 230（20×11.25），远低于 96×96 旧地图的全图绘制。
- 装饰/节点/掉落物只保留相机 2 屏内；区块外实体休眠。
- 地图面板打开时暂停世界更新，只重绘地图（地图本身缓存为贴图，缩放/平移不重算）。
- 不使用实时 shader、不使用大面积 blur；夜间用矩形 + 径向渐变贴图。
- 目标：1920×1080 下 60 FPS；集显也不低于 45 FPS。

## 10. 实施顺序

1. **资产与字体底座**：`build-assets`、`build-terrain-atlas`、`theme.ts`、`text.ts`、字体加载、整数缩放。
2. **世界生成**：`generate.ts` / `regions.ts` / `landmarks.ts` + 单测；先用调试视图渲染全岛缩略图验证形状与地标。
3. **区块渲染**：`chunks.ts`、地形视觉层、水面动画、装饰、资源节点、建筑、角色，移除 `makeTextures()` 与 Tiled 依赖。
4. **存档 v2**：seed/explored/discovered、v1 迁移、导入导出校验。
5. **HUD**：时钟/营地/状态/目标/提示/快捷栏/横幅/当前区域。
6. **面板**：背包、合成、建造、劳工。
7. **全岛地图**：地图渲染、迷雾、地标、路径点、缩放平移。
8. **暂停/死亡**：统一主题。
9. **打磨**：阴影、光照、低状态提示、tooltip、滚动、按钮反馈。
10. **验收**：测试、截图、README/LICENSES、部署。

每一步都保持可运行；第 3 步完成后就能看到最大的视觉提升，第 5–7 步解决“界面不好看”和“没有探索感”。

## 12. 风险与对策

| 风险 | 对策 |
|---|---|
| Tiny 素材拼装感 | 只用 Kenney Tiny/Pixel Adventure；共享色板；阴影/夜间 tint 统一 |
| 16px 树/建筑太小 | 树/棚屋/石墙做 16×32、32×32 或 64×64 预制体；加脚下阴影 |
| 字体加载失败或仍糊 | 启动 await 字体；只使用 12/24px；整数缩放；截图验收 |
| 10000×6000 生成不可控 | 纯函数生成器 + 单测断言；调试缩略图；`worldHash` 校验 |
| 大地图区块切换卡顿 | 每帧最多烘焙 1 块；3×3 区块上限；实体休眠 |
| 存档体积膨胀 | 只存种子/探索位图/实体差异；探索位图 240 字节 |
