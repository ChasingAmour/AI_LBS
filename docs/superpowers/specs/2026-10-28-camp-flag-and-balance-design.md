# 据点旗、生存手感与野生动物 设计

- 日期：2026-10-28
- 状态：待实现
- 规模：项目级（新增动物系统 + 据点系统 + 存档 v4 迁移 + 若干数值/UI 调整）
- 关联：`2026-10-28-robinson-crusoe-survival-design.md`、`2026-10-28-phase2-equipment-dungeon-design.md`

## 一、意图

试玩反馈暴露了这些问题：据点在哪儿不是玩家决定的、营地范围看不见；树太稀且再生太慢；精力只能靠睡觉恢复，白天没事干就只能干耗；没精力时采集直接被拒绝；食物回复多少完全不可见；采集时开背包会打断；夜里没有光源也自带一圈光；岛上除了野人没有任何活物。

本次改动解决以上八点。核心新增是两件事：**据点由玩家插旗决定**，**岛上有可猎杀的野生动物并产出肉类**。

## 二、目标与非目标

**目标**

1. 据点由玩家插旗决定：旗子 1 木头、全岛任意可站位置、插下即永久据点。
2. 建造模式里画出据点范围圈。
3. 资源更密、树和岩石再生更快。
4. 站着不动缓慢回精力；没精力也能采集，只是更慢。
5. 采集引导期间打开背包不打断采集。
6. 夜晚随身光源只来自道具，亮度与范围由道具数据决定。
7. 食物/消耗品的回复数值在背包 tooltip 里直接可读。
8. 岛上有小型与大型野生动物，可猎杀获得生肉；生肉可在篝火烤制、在晾肉架做肉干。
9. 沉船入口可见：画舱口贴图、地图与小地图独立图标，且不再需要火把。
10. 状态条可收起为四条细线，点击切换，收起状态进存档。

**非目标**

- 不做旗子搬家、多据点。
- 不做动物驯养、繁殖、皮革/骨头的制作链。
- 不改入侵时间与野人强度，不改装备数值，不改副本内容。
- 不改资源点掉落表与采集耗时。
- 动物不进入沉船副本。

## 三、约束

- 纯前端，`src/core` 不依赖 Phaser；新逻辑落在 `systems/`、`data/`、`entities/` 的纯状态层。
- 现有单元测试、`typecheck`/`lint`/`build` 必须全部通过。新规则会与既有断言冲突，**允许同步更新这些断言**，验收标准是"全绿"而不是"数量不变"。已知需要改写的文件：`buildingSystem`、`campSystem`、`tutorialSystem`、`saveV3`、`resourceSystem`。
- 存档键名仍为 `robinson.save.v1`，数据结构版本 3 → 4，旧档必须可迁移。
- 节点 id 由「类型_区块_区块_序号」构成且被 `world.nodeStates` 引用，改变撒点规则会使其错位。
- 640×360 基准分辨率，同时存在的动物数量要控制在个位数，避免掉帧。

## 四、方案与取舍

| 议题 | 选定方案 | 理由 |
|---|---|---|
| 旗子 | 作为普通建筑类型进 `BUILDINGS`，放置时写 `camp.center` | 复用建造菜单、幽灵预览、存档与坐标同步 |
| 密度/再生 | 直接调参，v4 迁移清空 `nodeStates` | 规则单一；重置的只是"哪棵树被砍了" |
| 精力 | 静止回 1.5/秒；没精力时采集照常但变慢 | 贴合"站着不动缓慢恢复"，不堵死玩法 |
| 食物数值 | 效果并入物品数据，tooltip 自动生成 | 单一数据源，避免两处数值漂移 |
| 动物 AI | 新建独立 `animals` 状态 + 纯函数 AI，与 `savages` 并列 | 野人是入侵 AI（拆墙、绑人），动物行为完全不同，混用会互相污染 |
| 动物渲染 | 复用 Tiny Farm 图集帧，找不到合适帧就程序化绘制 | 与 `palm`、玩家帧的既有做法一致 |

被否方案：独立据点系统（重复实现预览/存档）、偏移网格补点（两套规则）、物品表硬写描述（双份数值）、动物复用 `SavageState`（字段与语义都不匹配）。

## 五、行为规格

### 5.1 旗子与据点

**数据**：`BUILDINGS` 新增 `flag`，`name: '据点旗'`，`cost: [{ wood, 1 }]`，`unlockLevel: 0`，`blocks: false`。`BuildingDef` 增加两个可选字段 `unique?: boolean`、`indestructible?: boolean`，`flag` 两者都置真。

**放置规则**（`canPlace` 特判）：

- 已有旗子 → 拒绝，原因「据点已建立」。
- 无旗子时放置其它建筑 → 拒绝，原因「先插旗建立据点」。
- 旗子跳过营地半径检查；其余建筑仍受 `campRadiusTiles = 12` 限制。
- 水域、资源点、敌人占据、材料不足的检查对旗子同样生效。

**放置成功**：写入 `state.camp.center = { x: tileX, y: tileY }`，广播 `camp:flagPlaced`，横幅「据点已建立」，刷新教程。营地等级、囚犯上限、入侵刷怪点随之生效。

**不可移除**：`demolishBuilding` 与 `damageBuilding` 遇到 `indestructible` 直接返回；`unique` 保证只有一面旗。

**开局**：`setupTerrain()` 不再用生成器的营地坐标覆盖 `camp.center`。`camp.center` 初始化为破船附近坐标，仅作未插旗时的兜底（入侵刷怪点用），此时营地功能不启用：`checkCampUpgrade` 在无旗时直接返回 0。

**范围圈**：进入建造模式（选中建筑、跟随鼠标预览）时绘制以旗子为中心、半径 12 格的世界坐标圆：虚线描边 `0xd8f7b0`、填充同色透明度 0.08。退出建造模式即清除。未插旗时不绘制。

**地图**：小地图与全岛地图在旗子位置绘制旗标。

### 5.2 资源密度与再生

`src/world/nodes.ts`：

- 撒点网格 `STRIDE` 12 → 9，候选丢弃阈值保持 `roll > 0.5`。
- 森林：树 0.70 → 0.85，藤蔓 0.88 → 0.95，其余浆果。
- 草地：树 0.42 → 0.55，浆果 0.62 → 0.72，藤蔓 0.78 → 0.85，岩石 0.92 → 0.95，其余黏土。
- 沙滩、岩石地、黏土地、浅水的比例不变。

`src/data/spawns.ts`：树 `respawnDays` 3 → 1，岩石 5 → 2，其余不变。

### 5.3 精力恢复

`needsSystem` 新增 `tickEnergyRegen(state, dtSec, idle)`：

- `idle` 为真时每秒回复 1.5，上限 `deriveStats(state).energyMax`，下限 0。
- 由 `IslandScene.update` 在移动逻辑之后调用；`idle` 判定：玩家速度 < 1、未在引导交互/采集、未在攻击冷却中、未打开面板。
- 跑动消耗、采集每下 5、攻击/建造 10 的既有规则不变。

### 5.4 采集与精力不足

现状：`IslandScene` 在采集开始前 `spendEnergy` 失败就直接弹「精力不足」并拒绝。

改为：

- 精力不足时**仍然开始采集**，引导时间 ×2（与徒手 ×3 叠加），精力保持 0，横幅提示「精力不足，采集变慢」。
- 精力足够时行为不变（照常扣费、正常时长）。
- 采集完成的掉落与再生逻辑不变。

### 5.5 采集与背包

现状：`IslandScene.update` 里只要 `uiOpen`（任意面板）就 `cancelChannel()`。

改为：

- `UIScene` 额外维护 `registry.uiPanel`：`'inventory' | 'build' | 'craft' | 'labor' | 'map' | 'adventure' | 'pause' | null`。
- 采集引导期间打开**背包**不取消引导，引导条继续走，到点照常结算。
- 打开其它面板仍然打断。
- 面板打开时玩家仍被冻结，不会出现"一边跑一边采集"。
- 采集期间吃背包里的食物、换装备都不影响本次引导。

### 5.6 随身光源

现状：夜里玩家始终有 48px 光，背包里有耐久 > 0 的火把时变 64px，数值写死在 `torchLightSize()`。

改为：

- `ItemDef` 增加可选 `light?: { radius: number; brightness: number }`，火把填 `{ radius: 64, brightness: 0.85 }`。
- 判定：背包中存在带 `light` 且耐久 > 0 的道具 → 有光；否则**完全无光**，只受夜晚遮罩影响。
- 范围 = `radius`（`setDisplaySize`），亮度 = `brightness`（`setAlpha`）。
- 多个光源道具取 `radius` 最大者；耐久归零即失去光。
- 建筑灯光（营火等）不受影响，仍只在夜里显示。

### 5.7 食物数值

- `ItemDef` 增加可选 `food?: { hunger?: number; thirst?: number; heal?: number; healOverSec?: number }`；椰子、浆果、烤鱼、鱼干、绷带的效果从 `needsSystem.FOOD_EFFECTS` 迁入 `items.ts`，新增的肉类一并写入。
- `consumeFood` 改读 `ITEMS[id].food`，行为不变。
- 背包 tooltip 在「名称 · 类型」下方按效果生成行：「饱食 +10」「口渴 +15」「回复 30 生命（8 秒）」，只列非零项。
- 快捷栏不做改动：`ensureHotbar` 只接受 `tool`/`weapon`，食物进不了快捷栏，所以原本设想的快捷栏提示不会触发，属于死代码，本次不做。

### 5.8 动物与狩猎

**物种**（`src/data/animals.ts`）：

| id | 名称 | 体型 | 生命 | 伤害/次 | 攻击间隔 | 生肉 | 栖息地 |
|---|---|---|---|---|---|---|---|
| `chicken` | 野鸡 | 小 | 12 | 2 | 1.5s | 1–2 | 草地、森林 |
| `rabbit` | 野兔 | 小 | 10 | 1 | 1.5s | 1 | 草地、森林 |
| `boar` | 野猪 | 大 | 60 | 10 | 1.5s | 3–4 | 森林、高地、石阵 |

**状态**：`AnimalState { id, type, x, y, hp, mode: 'wander' | 'retaliate' | 'dead', cooldown, wanderDir, wanderTimer, disengageTimer }`，挂在 `GameState.animals: AnimalState[]`，与 `savages` 并列。

**生成**（邻近管理式，不是"一天只刷一次"）：

- 首次进入白天场景且 `animals` 为空 → 立即生成一批。
- 之后每个黎明 06:00 再补一次；同一白天内玩家走动后每 10 秒检查一次，不足上限就补。
- 生成点：玩家周围 **200–500px**（相机 2× 缩放，可视区仅 320×180，所以这个距离在视野外沿，走过去就能撞见），按栖息地瓦片挑点，避开水面与建筑；上限 6 只小型 + 3 只大型。
- 位置用世界种子 + 天数 + 序号做确定性哈希，同一天同一存档刷在同一批位置。
- 玩家离开超过 **900px** 的动物离场；进入夜晚 20:00 后全部离场。离场后玩家再回来会按同样的确定性位置重新补上，所以探索不会把岛走空。
- 状态写入存档；读档后不重置已有动物。

**行为**（`src/systems/animalSystem.ts`，纯函数，接受 `isWater(tileX, tileY)` 回调）：

- **游荡**：每 2–4 秒随机换向，速度 20px/s，撞到深水或世界边界就换向。**永不主动攻击玩家。**
- **反击**：被玩家命中后进入 `retaliate`。以 45px/s 追向玩家，距离 ≤ 20px 时按攻击间隔对玩家造成伤害（走 `applyDamage`）。
- **脱战**：玩家离开 400px 并持续 5 秒 → 回到 `wander`，生命不回满。
- **死亡**：生命归零 → `dead`，掉落直接进背包（`addItem`，背包满则落到 `world.groundLoot`），横幅「获得 生肉×N」，尸体在场景里淡出 1 秒后移除。
- 动物不拆建筑、不攻击劳工、不触发入侵逻辑。

**战斗接入**：`IslandScene.attack()` 的目标集合由「野人」扩展为「野人 + 动物」，命中路由按 id 前缀区分；新增 `applyHitToAnimal(animal, weapon, mods)`，不套用野人的眩晕条。

**渲染**：每只动物一个精灵，按 `y` 排序深度，与野人同步逻辑一致；图集帧从 Tiny Farm 里选，找不到合适帧就程序化绘制 16×16 帧（与 `palm` 的做法一致）。

### 5.9 肉类与烹饪

- 新物品：`raw_meat` 生肉（材料，不可直接吃）、`cooked_meat` 烤肉（食物，饱食 +40）、`dried_meat` 肉干（食物，饱食 +30）。
- 新配方：`cooked_meat`（篝火站，生肉 ×1 → 烤肉 ×1，2 秒）、`dried_meat`（晾肉架，生肉 ×1 → 肉干 ×1，900 秒）。
- 「和篝火交互」走现有合成面板的 campfire 站点，不新增"对着篝火按 E"的独立流程。
- 入侵结算的 `FOOD_PRIORITY` 追加 `cooked_meat`、`dried_meat`。

### 5.10 沉船入口

现状：`wreckEntrance = { x: landmark.x + 24, y: landmark.y }` 只是一个坐标，没有贴图、不在地图上，只有站到 34px 内才会出现「进入沉船」提示。

改为：

- **贴图**：在入口坐标画一个 16×16 舱口（`dungeon` 图集帧），带地面阴影，按 `y` 排序深度；与破船宝箱错开 24px。
- **地图**：全岛地图与小地图上，在入口坐标画独立图标；「破船」地标文字仍然画在地标坐标，两者按地图比例换算后不重叠。未发现时不画，沿用现有地标发现规则。
- **取消火把门槛**：`enterDungeon()` 删除 `hasTorch` 判定，空手也能进。`DungeonScene` 的灯光逻辑不变——没有火把时只有 40px 微光，进去就是摸黑。
- 野人入侵期间禁止进入的规则不变。

### 5.11 状态条收起

现状：状态面板固定 176×104（`HUD.status`），四行「图标 + 文字 + 条 + 数值」。

改为：

- 面板右上角加一个 10×10 的小箭头按钮，点击切换展开/收起。
- 收起后面板变成 176×30：左侧一列 8px 小图标（生命/饱食/口渴/精力），右侧四条 4px 高、120px 宽的细线，颜色沿用现有四色；不显示文字与数字。
- 目标条随之上移到 `y = 78`，展开时恢复 `y = 156`。
- 收起状态写入 `settings.hudCompact`，读档保持。

## 六、存档 v3 → v4 迁移

`SAVE_VERSION` 3 → 4，迁移必须保证旧档不卡死：

1. 清空 `world.nodeStates`（撒点规则已变，旧 id 会错位）。
2. `flags.tutorialStep += 1`（教程链最前面新增「插下据点旗」）。
3. 若 `state.buildings` 非空且没有旗子，在 `camp.center` 所在格补一面旗，保持旧营地照常运作。
4. 新增 `animals: []`、`settings.hudCompact = false`。
5. 其余字段（角色、时间、背包、装备、营地等级、副本状态、设置）原样保留。

## 七、教程链

`TUTORIAL_GOALS` 最前面插入 `{ id: 'flag', label: '插下据点旗' }`，完成条件为存在旗子建筑；后续步骤索引顺延。

## 八、数据校验

`dataValidation.ts` 需要覆盖：新建筑 `flag`、新物品 `raw_meat`/`cooked_meat`/`dried_meat`、新配方、`animals.ts` 的物种表（栖息地瓦片合法、掉落物品存在、数值为正）。

## 九、测试要点

- `canPlace`：无旗时拒绝其它建筑；旗子忽略半径；第二面旗被拒；水域/资源点/敌人仍拦截。
- `demolishBuilding` / `damageBuilding` 对旗子无效；插旗后 `camp.center` 更新；无旗时 `checkCampUpgrade` 返回 0。
- 迁移：v3 档读入后 `nodeStates` 为空、`tutorialStep` +1、无旗旧档被补旗、`animals` 为空数组。
- `tickEnergyRegen`：静止回复速率、非静止不回、不超上限。
- 采集：精力不足仍开始且时长 ×2、精力不为负；背包打开时引导不取消，其它面板仍取消。
- 光源：无火把时不可见；有火把时尺寸/透明度来自数据；耐久为 0 时无光。
- 食物：`consumeFood` 按数据生效；tooltip 行只含非零项。
- 动物：游荡状态永不造成伤害；被命中后进入反击；离开 400px 满 5 秒脱战；死亡掉落数量落在表内且背包满时落到地面；刷新数量不超过上限；确定性哈希同种子同日同位置；玩家走远再回来会重新补足；首次进入白天场景就有动物。
- 烹饪：两个配方存在、站点正确、产物正确。
- 沉船入口：`enterDungeon` 不再依赖火把；入口坐标 = 破船地标 +24px。
- 状态条：收起后 `hudCompact` 写入存档并读回；收起/展开时目标条 y 值正确切换。
- 回归：现有测试全部保持通过（允许同步更新与新规则冲突的断言）。
