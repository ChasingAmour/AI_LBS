# 鲁滨孙：荒岛求生

基于《鲁滨孙漂流记》的单机网页像素生存游戏。纯静态前端，无后端，使用 TypeScript + Phaser 3 + Vite 构建，可部署到 GitHub Pages。

## 本地运行

需要 Node.js 22.8.0 或更高版本（已在 22.8.0 上验证）。

```bash
npm install
npm run dev
```

打开终端输出的地址（默认 `http://localhost:5173/AI_LBS/`）。生产构建与预览：

```bash
npm run build
npm run preview
```

质量检查：

```bash
npm run test
npm run typecheck
npm run lint
```

## 操作

| 按键 | 功能 |
|---|---|
| WASD | 移动 |
| Shift | 奔跑 |
| E | 交互 / 采集 / 喝水 / 睡觉 / 开箱 / 捆绑野人 |
| 鼠标左键 | 攻击 / 确认建造 / 点击面板 |
| 鼠标右键 | 取消建造 |
| I | 背包 |
| C | 合成 |
| B | 建造 |
| L | 劳工 |
| Esc | 暂停 / 关闭面板 |
| 1–8 | 选择快捷栏 |

交互需要靠近目标并短暂引导，移动或打开面板会打断。采集树、岩石、黏土需要石斧/石镐才能全速；徒手采集耗时三倍。

## 存档

- 自动存档：每天 06:00、营地升级、建造、睡觉、死亡重生。
- 手动存档：`Esc` → 保存进度。
- 存档保存在浏览器 `localStorage` 的 `robinson.save.v1`，上一份自动备份为 `robinson.save.v1.bak`。
- 主存档损坏时自动回退备份；两份都损坏则开始新游戏。
- `Esc` 暂停菜单支持导出/导入 JSON 存档。导入会覆盖当前进度并重载岛屿。

## 阶段一内容

- 96×96 手工占位岛、16px 瓦片、2.5D 深度遮挡、昼夜光照。
- 一游戏日 900 秒（白天 600 / 夜晚 300），第 5 天周五 17:00 预警、18:00 入侵。
- 生命/饱食/口渴/精力、进食、喝水、睡觉、死亡掉落。
- 可破坏资源节点与再生、唯一宝箱、火把燃料。
- 手工/工作台/营火/晾肉架合成。
- 八种建筑、营地半径与等级 Lv0–Lv3、囚犯上限。
- 拳头/木棒/石矛、攻击形状与眩晕、周五入侵 AI、黎明口粮结算。
- 击晕野人后用藤蔓活捉，首位劳工命名为“星期五”；指派采集、每日口粮、断粮逃跑。
- 中文 HUD、面板、第一天目标链、暂停/死亡场景。
- 版本化本地存档、备份回退、JSON 导入导出。

阶段二将加入装备三槽/品级/词条、鞋子移速与三层沉船副本。

## 目录结构

```
src/
  core/        GameState、事件总线、随机数、配置（不依赖 Phaser）
  data/        物品、配方、建筑、营地等级、武器、资源与宝箱数据
  entities/    Phaser 精灵包装
  scenes/      Boot / Island / UI / Pause / Death
  systems/     时间、需求、背包、资源、合成、建筑、营地、战斗、入侵、劳工、存档、交互、教程
  ui/          HUD 与各面板
  world/       地形与深度排序、A* 寻路
public/assets/ 地图与占位贴图
scripts/       占位地图生成器
tests/unit/    Vitest 单元测试
```

## 部署

推送到 `main` 后，GitHub Actions（`.github/workflows/deploy.yml`）会执行测试与构建并发布到 GitHub Pages。`vite.config.ts` 的 `base` 固定为 `/AI_LBS/`，与仓库路径一致。

## 已知限制

- 首版仅桌面浏览器，不支持手机触屏。
- 地图与贴图均为占位素材，后续可替换为 Tiled 手工地图与正式像素素材。
- 未内置 Fusion Pixel 字体文件，中文当前使用系统等宽字体回退。
