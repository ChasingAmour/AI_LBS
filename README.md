# 鲁滨孙：荒岛求生

基于《鲁滨孙漂流记》的单机网页像素生存游戏。纯静态前端，无后端，使用 TypeScript + Phaser 3 + Vite 构建，可部署到 GitHub Pages。

## 本地运行

需要 Node.js 22.8.0 或更高版本（已在 22.8.0 上验证）。

```bash
npm install
npm run dev
```

打开终端输出的地址（默认 `http://localhost:5173/AI_LBS/`）。生产构建与预览：

```bash
npm run build
npm run preview
```

质量检查：

```bash
npm run test
npm run typecheck
npm run lint
```

## 操作

| 按键 | 功能 |
|---|---|
| WASD | 移动 |
| Shift | 奔跑 |
| E | 交互 / 采集 / 喝水 / 睡觉 / 开箱 / 捆绑野人 |
| 鼠标左键 | 攻击 / 确认建造 / 点击面板 |
| 鼠标右键 | 取消建造 / 地图上清除路标 |
| I | 背包（6×4 物品格、装备槽、tooltip） |
| C | 合成 |
| B | 建造 |
| L | 劳工 |
| M | 全岛地图（羊皮纸迷雾、探索度、地标、路标）；右上角小地图可点击打开；点击已发现地标传送 |
| R | 冒险等阶（探索、地标、装备评分、副本进度） |
| Esc | 暂停 / 关闭面板 |
| 1–8 | 选择快捷栏 |

交互需要靠近目标并短暂引导，移动或打开面板会打断。采集树、岩石、黏土需要石斧/石镐才能全速；徒手采集耗时三倍。深水不可通行，浅水与河流会减速。

画面使用 640×360 基准分辨率与整数倍缩放：1920×1080 为 3×，1366×768 为 2× 并自动加黑边，不会出现分数缩放造成的模糊。

## 世界

- 每座岛 10,000×6,000 世界像素（625×375 个 16px 瓦片，约 31×33 屏），由种子确定性生成。
- 5 个区域：海岸平原、雨林、高地、潮汐湾、石阵荒野。
- 7 个地标：破船、营地、淡水泉、瞭望岩、石阵、海蚀洞、旧营地，由小径与河流连接。
- 32×32 区块流式加载：每帧最多烘焙一个 512×512 区块，离开视口即释放。
- 一游戏日 900 秒（白天 600 / 夜晚 300），第 5 天周五 17:00 预警、18:00 入侵。

## 存档

- 自动存档：每天 06:00、营地升级、建造、睡觉、死亡重生。
- 手动存档：`Esc` →「保存进度」。
- 存档版本为 **v2**（`robinson.save.v2` 数据结构，键名仍为 `robinson.save.v1` 以兼容旧档），保存世界种子、地形哈希、探索位图、已发现地标与路标，不保存地形本身。
- v1 旧档会在读取时自动迁移：保留角色、时间、背包、装备、营地等级，建筑与劳工按相对位置移动到新营地附近，世界重新生成。
- 主存档损坏时自动回退备份；两份都损坏则开始新游戏。
- `Esc` 暂停菜单支持导出/导入 JSON 存档。导入会覆盖当前进度并重载岛屿。

## 阶段一内容

- 6 个椭圆瓣 + 双层 domain warp + fBm 生成的 625×375 岛屿，海岸线、沙滩、雨林、高地、潮汐湾与河流。
- 像素素材：Tiny Town / Battle / Dungeon / Farm + UI Pack Pixel Adventure；Fusion Pixel 12px 中文像素字体。
- 生命/饱食/口渴/精力、进食、喝水、睡觉、死亡掉落。
- 可破坏资源节点与再生、唯一宝箱、火把燃料。
- 手工/工作台/营火/晾肉架合成。
- 八种建筑、营地半径与等级 Lv0–Lv3、囚犯上限。
- 拳头/木棒/石矛、攻击形状与眩晕、周五入侵 AI、黎明口粮结算。
- 击晕野人后用藤蔓活捉，首位劳工命名为“星期五”；指派采集、每日口粮、断粮逃跑。
- 中文 HUD、背包、合成、建造、劳工面板，第一天目标链，暂停/死亡场景。
- 羊皮纸全岛地图：迷雾、探索度、已发现地标、玩家箭头与路标；右上角常驻小地图，点击已发现地标可传送。
- 建造预览：可建位置绿色高亮 + 角标，不可建位置红色叉号并显示原因。
- 阶段二：武器/护甲/鞋子三槽、5 品级、随机词条、传说唯一词条、耐久修理与掉落表。
- 三层种子生成沉船副本：敌人、机关、火把照明、每周宝箱重置、首通传说保底。
- 角色行走两帧动画、攻击月牙斩击（跟随玩家、不脱节）；CC0 音效与暂停菜单音效开关。
- 版本化本地存档、备份回退、JSON 导入导出、v1 → v3 迁移。

阶段二将加入装备三槽/品级/词条、鞋子移速与三层沉船副本。

## 目录结构

```
src/
  core/        GameState、事件总线、随机数、噪声、缩放、存档版本（不依赖 Phaser）
  data/        物品、配方、建筑、营地等级、武器、资源与宝箱数据
  entities/    玩家、野人、劳工、建筑、资源节点精灵
  scenes/      Boot / Island / UI / Pause / Death
  systems/     时间、需求、背包、资源、合成、建筑、营地、战斗、入侵、劳工、存档、交互、教学
  ui/          HUD、面板、地图、图标与通用控件
  world/       地形生成、区块、地标、小径、光照、地图坐标（纯函数）
public/assets/ 瓦片、UI、字体
scripts/       资源校验脚本
tests/unit/    Vitest 单元测试
```

## 部署

推送到 `main` 后，GitHub Actions（`.github/workflows/deploy.yml`）会执行测试与构建并发布到 GitHub Pages。`vite.config.ts` 的 `base` 固定为 `/AI_LBS/`，与仓库路径一致。

> GitHub Pages 需要在仓库 `Settings → Pages → Build and deployment → Source` 选择 **GitHub Actions** 才能首次发布。

## 已知限制

- 首版仅桌面浏览器，不支持手机触屏。
- 全岛地图为固定 1× 视图，暂不支持缩放与拖动（已支持点击地标传送）。
- 建造/劳工面板仍为列表布局，卡片式布局留待后续打磨。
- 60 FPS 尚未在目标机器实测。
- 存档版本 3（键名仍为 `robinson.save.v1`），v1/v2 自动迁移。
